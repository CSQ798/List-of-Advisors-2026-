# List-of-Advisors-2026-
2026级本科生导师信息速查
上海交通大学 2026 级本科生导师名单的可检索网页版：65 位导师的姓名、职称、院系、邮箱、个人主页与研究方向一页速查，点「个人主页 ↗」即可直接查看老师自己的自我介绍。

数据整理自《2026本科生导师名单.pdf》；简介内容来自各位老师个人主页的公开发布内容（2026 年抓取），仅用于选导师时快速了解，请以老师主页与学院官方通知为准。

在线访问
主页：https://你的用户名.github.io/仓库名/（GitHub Pages 启用后）
手机扫码：打开页面后地址栏链接可直接分享；index-qr.html 为带二维码横幅的版本
功能
关键词搜索：姓名 / 职称 / 院系 / 邮箱 / 研究方向 / 简介全文，实时过滤并高亮
方向标签筛选：185 个研究方向标签，可多选叠加（如「具身智能」+「强化学习」）
院系、职称筛选，以及「仅看双聘教师」
一键复制邮箱、个人主页直链
每张卡片：序号、姓名、职称、院系、研究方向标签、中文简介（可展开全文）
支持「打印 / 导出 PDF」
数据说明
姓名 / 职称 / 邮箱 / 个人主页链接：从 PDF 表格文字与链接注释中提取，共 65 位，序号 1–65 与 PDF 一一对应。
院系 / 单位：PDF 备注列；备注为「双聘教师」的 20 位已按实际所属院系归类，并保留「双聘教师」标记。
简介与研究方向标签：抓取各位老师个人主页的公开发布内容整理而成。
已标注的个别数据问题：
序号 12 郭宁：PDF 中邮箱后缀显示为 sjtu.edu.en，可能为 sjtu.edu.cn 笔误；
序号 15 李永露、41 赵波：PDF 单元格内邮箱显示不全，采用 PDF 链接中的完整地址；
序号 21 任麒冰：PDF 名单无主页链接，页面按其邮箱推断的主页提供。
