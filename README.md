# 2026 级本科生导师信息速查

由 `2026本科生导师名单.pdf` 整理生成，用于选导师时快速检索、一键跳转到导师个人主页查看自我介绍。

## 文件

| 文件 | 说明 |
| --- | --- |
| `导师信息速查.html` | **主交付物**。单文件网页，双击即可用浏览器打开，无需联网、无需服务器 |
| `导师名单.csv` | 同一份数据的表格版（UTF-8 BOM，可直接用 Excel 打开） |

## 网页功能

- **关键词搜索**：姓名、职称、院系、邮箱、研究方向、简介全文模糊匹配
- **方向标签筛选**：185 个研究方向标签，可多选叠加（例如「具身智能」+「强化学习」）
- **院系 / 职称筛选**，以及「仅看双聘教师」
- **一键复制邮箱**、**个人主页直链**（新标签页打开，直接查看老师自我介绍）
- 每张卡片展示：序号、姓名、职称、院系、研究方向标签、简介摘要（可展开全文）
- 支持「打印 / 导出 PDF」，打印时自动只保留卡片列表

## 分享给别人

`导师信息速查.html` 是单文件网页（零依赖、可离线），分享方式见 **`分享说明.md`**，三种常用做法：

1. **直接发文件**：邮件附件最稳妥；微信/QQ 发送后需保存再用浏览器打开。
2. **传网盘发链接**：百度网盘、阿里云盘等支持在线预览 HTML。
3. **挂到网上拿网址**：GitHub Pages 或 Netlify Drop 拖拽上传即可；有了网址后可执行
   `python .tools\build_share.py "https://你的网址/导师信息速查.html"` 生成带二维码的 `导师信息速查-带二维码.html`。

- **姓名 / 职称 / 邮箱 / 个人主页链接**：从 PDF 的表格与链接注释中提取，共 **65 位**导师，与 PDF 一一对应（序号 1–65）。
- **院系 / 单位**：PDF 备注列。PDF 中备注为「双聘教师」的 20 位老师，已按其所属院系归类并保留「双聘教师」标记。
- **简介与研究标签**：抓取各位老师**个人主页**的公开发布内容整理而成（抓取时间：生成当日），仅用于快速了解，请以老师主页和学院官方通知为准。

  - 序号 15 李永露、序号 41 赵波：PDF 单元格内邮箱显示不全或被截断，已采用 PDF 链接中的完整地址并标注。

## 重新生成

`.tools/` 目录下为生成脚本（PDF 解析、抓取、构建）：

```powershell
python .tools\makedata_final.py    # PDF -> 结构化名单
python .tools\extract_intros2.py   # 个人主页 -> 简介素材
python .tools\build_data.py        # 合成最终数据（含人工校订）
python .tools\build_page.py        # 生成 导师信息速查.html
```
